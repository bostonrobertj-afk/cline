## Scope

Build the `acceptance-audit-review` workflow module from the approved module requirements. The module must support parent-invoked child execution from Code Review and direct main-thread slash/use-skill activation, generate or reuse the review-scope manifest using the established Code Review helper, allocate the `acceptance-audit-{target}.md` output artifact, project the acceptance audit prompt and tool surface, complete on `attempt_completion`, and register the workflow through the shared runtime registry.

## Scope Boundary

This plan must not implement legacy migration or cleanup targets for Acceptance Audit Review because the requirements state there are none. This plan must not create module-owned document helper, registry, or static data files. This plan must not add compatibility aliases for `acceptance-audit-review.md` or any other markdown-suffixed workflow name. This plan must not modify story status, move story files, launch subagents, invoke `use_skill`, or mutate a parent workflow session after Acceptance Audit Review completes.
